# Weentai

Private co-op website for two friends, with local browser playtime history and a small temporary presence service.

The site itself is published separately through InfinityFree. `server.js` will be deployed as a Render WebSocket service. Do not commit Moonlight-Web invitation URLs, credentials, or personal game files.

The presence service only keeps host/invite state in process memory; it does not store playtime or stream media.
